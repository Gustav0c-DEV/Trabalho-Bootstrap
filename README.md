# Verde no Dia a Dia

Landing page educativa sobre sustentabilidade na rotina, desenvolvida como atividade acadêmica para praticar HTML, CSS e Bootstrap.

## Objetivo

Apresentar atitudes simples que podem contribuir para o uso consciente de água e energia, a redução de resíduos, o consumo responsável e o cuidado com áreas verdes.

## Tecnologias utilizadas

- **HTML5:** estrutura semântica e conteúdo da página.
- **CSS3:** identidade visual, cores, espaçamentos, ilustrações e ajustes responsivos.
- **Bootstrap 5.3.3:** navbar responsiva, grid, cards, carousel, botões e componentes de formulário.
- **JavaScript:** validação do formulário, mensagem de confirmação e atualização automática do ano no rodapé.

## Componentes do Bootstrap

1. **Navbar:** menu responsivo com links para as seções.
2. **Cards:** apresentação das seis atitudes sustentáveis.
3. **Carousel:** conjunto de ideias que o visitante pode navegar.
4. **Grid responsivo:** organização do conteúdo em colunas conforme o tamanho da tela.
5. **Formulário:** campos com validação no navegador.

## Formulário: observação importante

O formulário é demonstrativo. O JavaScript valida os campos e mostra uma mensagem na própria página, mas **não envia nem armazena dados em um servidor**. Para um cadastro real, seria necessário integrar um backend ou serviço apropriado.
