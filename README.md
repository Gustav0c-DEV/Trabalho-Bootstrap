# Verde no Dia a Dia

Landing page educativa sobre sustentabilidade na rotina, desenvolvida como atividade acadêmica para praticar HTML, CSS e Bootstrap.

## Objetivo

Apresentar atitudes simples que podem contribuir para o uso consciente de água e energia, a redução de resíduos, o consumo responsável e o cuidado com áreas verdes.

## Tecnologias utilizadas

- **HTML5:** estrutura semântica e conteúdo da página.
- **CSS3:** identidade visual, cores, espaçamentos, ilustrações e ajustes responsivos.
- **Bootstrap 5.3.3:** navbar responsiva, grid, cards, carousel, botões e componentes de formulário.
- **JavaScript:** validação do formulário, mensagem de confirmação e atualização automática do ano no rodapé.

## Componentes do Bootstrap

1. **Navbar:** menu responsivo com links para as seções.
2. **Cards:** apresentação das seis atitudes sustentáveis.
3. **Carousel:** conjunto de ideias que o visitante pode navegar.
4. **Grid responsivo:** organização do conteúdo em colunas conforme o tamanho da tela.
5. **Formulário:** campos com validação no navegador.

## Como executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador. Para uma experiência de desenvolvimento melhor, você também pode usar a extensão Live Server.
4. É necessária conexão com a internet para carregar o Bootstrap e as fontes externas via CDN.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `trabalho-bootstrap-sustentabilidade`.
2. Envie os arquivos e pastas deste projeto para a raiz do repositório. O arquivo `index.html` precisa ficar na raiz.
3. No repositório, abra **Settings**.
4. Entre em **Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/(root)` e clique em **Save**.
7. Aguarde o GitHub concluir a publicação. A URL será exibida na própria seção **Pages**, normalmente no formato `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Após alterar os arquivos, faça commit e push para a branch selecionada. O GitHub Pages atualizará o site.

## Formulário: observação importante

O formulário é demonstrativo. O JavaScript valida os campos e mostra uma mensagem na própria página, mas **não envia nem armazena dados em um servidor**. Para um cadastro real, seria necessário integrar um backend ou serviço apropriado.

## Apresentação sugerida (5 minutos)

- **0:00–0:40 — Introdução:** explique o objetivo da página e o tema sustentabilidade no dia a dia.
- **0:40–1:30 — Estrutura:** mostre a navbar e como os links levam às seções.
- **1:30–2:30 — Bootstrap:** demonstre os cards, o carousel e o grid responsivo.
- **2:30–3:30 — Formulário:** preencha os campos e mostre a validação e a mensagem de confirmação.
- **3:30–4:20 — Responsividade:** reduza a largura do navegador ou use o modo de dispositivo do DevTools.
- **4:20–5:00 — Tecnologias e conclusão:** explique o papel de HTML, CSS, Bootstrap e JavaScript e apresente a publicação no GitHub Pages.
